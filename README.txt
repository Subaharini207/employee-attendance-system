EMPLOYEE ATTENDANCE SYSTEM - ATTENDIFY PRO

1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Create virtual environment (optional):
   python -m venv venv
4. Activate on Windows:
   venv\Scripts\activate
5. Install:
   python -m pip install -r requirements.txt
6. Run:
   python app.py
7. Open:
   http://127.0.0.1:5000
8. Login:
   Username: admin
   Password: admin123

Features:
Dashboard, Employee Management, Check-in/Check-out, Leave Management,
Payroll Support, Reports, SQLite database, responsive UI.

This is a starter/demo project. Change the secret key and login credentials before real deployment.
